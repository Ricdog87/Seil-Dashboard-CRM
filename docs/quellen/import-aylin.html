Workflows in n8n importieren

Neun Dateien, immer derselbe Ablauf. Es wird nichts eingeschaltet und es geht nichts nach draußen – die Workflows werden nur abgelegt.

Vorbereitung

ZIP entpacken

Darin liegen neun Dateien und eine README. Die Dateien bitte nicht umbenennen und nicht in einem Editor öffnen.

01-datenraum-intake02-matching03-mail-vorbereitung04-freigabe-gate05-followup-scheduler06-antworterkennung07-status-report08-besichtigung09-datenraum-status-api
Der Ablauf

Sechs Klicks je Datei

  1. n8n im Browser öffnenDie Adresse eures Servers. Anmelden mit dem Zugang, den ihr beim Einrichten angelegt habt.
  2. Oben rechts auf Create WorkflowEs öffnet sich eine leere Arbeitsfläche.
  3. Oben rechts das Drei-Punkte-Menü öffnenDie drei Punkte stehen neben dem Save-Knopf.
  4. Import from File… auswählenJe nach Version heißt es auch „Importieren aus Datei“. Es ist immer der Eintrag mit File.
  5. Die Datei wählen, mit 01 anfangenAuf der Arbeitsfläche erscheinen jetzt mehrere verbundene Kästchen. Das ist richtig so.
  6. Oben rechts auf SaveDer Name des Workflows steht danach oben links.
Und jetzt achtmal dasselbe. Zurück zur Übersicht (oben links auf das n8n-Zeichen), wieder Create Workflow, Drei-Punkte-Menü, Import from File – mit 02, dann 03 und so weiter bis 09. Ab dem dritten Mal geht es schnell.

Zum Schluss prüfen

Geh auf die Übersicht. Dort müssen stehen:

  • Neun Workflows, von 01 bis 09
  • Bei jedem der Schalter auf Inactive
Bitte beachten

Drei Dinge

Nichts aktivieren. Der Schalter bleibt bei allen neun auf Inactive. Es gibt noch kein Postfach und keine echten Daten – eingeschaltet würden die Workflows nur Fehlermeldungen erzeugen.
Nichts in den Kästchen ändern. Auch wenn etwas unvollständig aussieht: Das ist Absicht, die fehlenden Teile kommen von der IT.
Bei einer Fehlermeldung nicht selbst reparieren. Kurz Bescheid sagen, mit Screenshot. Die Datei ist dann vermutlich beschädigt, und eine neue ist in zwei Minuten da.
Sieht ein Menü anders aus als hier beschrieben? n8n-Versionen unterscheiden sich leicht. Der Eintrag heißt immer Import from File – danach suchen, nicht raten.
